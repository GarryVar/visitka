### CSS

- **Flexbox** — создание гибких макетов, работа со свойствами `display: flex`, `flex-direction`, `flex-grow` и др.
- **CSS Grid** — мощные сеточные макеты: `grid-template-areas`, `grid-row`, `grid-column`.
